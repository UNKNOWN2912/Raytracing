# Introduction
A raytracing program using compute shader in vulkan. The purpose of this project is to learn math behind raytracing and also to build a graphics library using vulkan

# Build
The project comes with a <u>build.sh</u> script
```
$ ./build.sh
```

# Dependencies
- glfw
- stb
- glm
- vulkan sdk
